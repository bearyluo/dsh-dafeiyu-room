- 从锁文件安装开发依赖；SDK 保持 0.2.1-rc.5，Zod root override 为 4.6.6。

- 逐文件比较 APK 内置渲染器及素材与发布源码，内容一致。保留前一测试版的开发签名，以支持覆盖安装。
